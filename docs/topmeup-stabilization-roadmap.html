The short version

What this pass protects.

No jargon required. These are the three outcomes we are designing around.

Safe payment

Paystack is checked on the server before any electricity is requested. A duplicate notification cannot create a second vend.

Safe vending

The provider flow is aligned to the latest R&A contract: confirm the customer, vend once, and keep the voucher details needed for a receipt.

Clear recovery

If the provider is unsure, the system checks the original request instead of guessing. Senders see a useful status, not a dead end.

Non-negotiables

The rules that protect trust.

These guardrails stay true even when a provider or payment response is slow.

01 / ONCE

Never send a second electricity vend just because the first response was slow.

02 / ADVICE

Check an uncertain original request through Advice instead of guessing.

03 / FULL VALUE

The sender's electricity amount reaches the vend in full.

04 / PRIVATE

Redact credentials, tokens, full meter numbers, and sender data from evidence.

05 / HONEST

Show “checking”, refund, or reconciliation when success is not yet known.

For the technical handoff

The short version behind the scenes.

This detail is here for anyone who wants to understand the engineering decisions without reading the source code.

Which provider operations are in the paid flow?

ConfirmCustomer confirms the meter and supplier, CreditVend requests the paid electricity, and Advice checks an original vend when the result is uncertain. The app now uses that current contract and stores the selected voucher code for the vend.

What happens when the provider times out?

The system does not send another vend. It records the original request, asks the provider for Advice using a new Advice request ID, and keeps the sender informed. If the bounded checks cannot establish the outcome, the case is held for reconciliation rather than guessed.

What is the domain plan?

topmeup.me is currently held in the registry dropzone and listed for auction, according to the registrar’s response. That is a separate commercial decision; the product can continue on a temporary hosted URL while the core flow is stabilized.
